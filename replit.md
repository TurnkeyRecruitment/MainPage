# Turnkey homepage

Read README.md and docs/REPLIT.md before changing the application.

This repository is the approved Turnkey company homepage. It must remain a compact hub linking to Core, Media and Arena. Preserve the design, capitalization and product wording. Arena is under development.

The production domain is https://www.turnkeyrecruitment.no. Norwegian is at `/`; English is at `/en/`.

Use Node.js 22 or newer. There are no external application dependencies. Build with `npm run build`, start with `npm start`, and verify with `npm run check`. Use `npm run dev` for a preview that disables indexing. The server listens on `0.0.0.0`, using `PORT` or 3000.

Keep the existing Replit project and domain connections when integrating this code. Preserve unrelated services and secrets. Review the completed preview before publishing an update to the live website.

Edit the source template, translations and stylesheet, then rebuild. Do not edit generated `worker/index.js` by hand. Maintain metadata, social sharing images, canonical URLs, language links, sitemap, explicit permanent redirects and proper 404 responses.
